Reinforcement Learning — Homework 8 
======================================

Files
-----
- fc_classification_mnist.py: Classification on MNIST digits 
- fc_classification_cifar.py: Classification on CIFAR-10
- fc_classification_synthetic.py: Classification on a 2D synthetic dataset + decision boundary plot
- model.py

All models use the same `FC` class defined in `model.py`.

How to run
----------
(1) Create a Python environment and install requirements.txt
(2) Run Classification on MNIST digits:
      python fc_classification_mnist.py
(3) Run Classification on CIFAR-10:
      python fc_classification_cifar.py
(4) Run Classification on a 2D synthetic dataset + decision boundary plot
      python fc_classification_synthetic.py
